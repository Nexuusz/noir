ETAPA 7: PACOTAR COMO WEBAPK

Como NÃO há Android SDK na máquina, as opções práticas:

OPÇÃO A: "ADICIONAR À TELA INICIAL" NO CHROME/EDGE ANDROID
- Acessar site no Chrome/Edge do Android/TV
- Menu (⋮) → "Instalar aplicativo" ou "Adicionar à tela inicial"
- Isso gera um WebAPK funcional automaticamente
- Não requer nenhuma modificação extra se o manifest estiver correto
- Esta é a opção mais recomendada atualmente

OPÇÃO B: TERMUX NO ANDROID
- Instalar termux no dispositivo Android
- Comandos: pkg update, pkg install python
- Usar ferramentas como webapk ou PWA2APK
- Mais complexo mas gera APK "nativo"

OPÇÃO C: CONVERSORES ON-LINE
- Sites como pwa2apk.netlify.app ou add2home.com
- Fazer upload do index.html + manifest.json + sw.js
- Baixar APK gerado
- Funciona para TV se manifest tiver configurações corretas
